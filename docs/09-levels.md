# 09. レベルモード — HAMARU

2026-09-18 追加(ユーザー判断: 難易度を段階的にしてレベルをクリアできるようにする。ランキングの対象にはしない)。

## 1. ルール

- レベル N(1 から上限なし)は**固定シード `level:N`** の面。全員が同じ面を遊ぶ
- **目標**: 決められた**トレイ数のうちに**、目標の**列数**を消す。達した瞬間にクリア
- **失敗**: 置けるピースが無くなる、またはトレイを使い切る(最後のトレイを置き終えても目標に届かない)
- **素焼きの欠片**: 開始時に盤にある障害物(セル値 7)。ピースと同じく、列がそろえば消える
- **星**: クリアした時点のトレイが、上限の 60 % 以内なら ★3、80 % 以内なら ★2、それ以外は ★1
- レベル N+1 は N をクリアすると解放される。何度でも遊び直せ、星と得点は最高を残す
- 得点の計算はエンドレスと同じ。ランキングには送らない(docs/08 の対象外)

## 2. 難易度のパラメータ(`game-config.json` の `levels`。改善ループが調整できる)

| キー | 既定 | 意味 |
|---|---|---|
| `goalBase` / `goalPerLevel` / `goalMax` | 3 / 0.25 / 15 | 目標列数 = `min(goalMax, goalBase + floor((N-1) × goalPerLevel))` |
| `traysPerLineStart` / `traysPerLineEnd` / `traysPerLineStep` | 2.0 / 1.1 / 0.02 | トレイ上限 = `ceil(目標 × max(End, Start − Step × (N-1)))` |
| `obstaclesPerLevel` / `obstaclesMax` | 0.3 / 18 | 欠片の数 = `min(obstaclesMax, floor((N-1) × obstaclesPerLevel))` |
| `starThree` / `starTwo` | 0.6 / 0.8 | 星の閾値(トレイ上限に対する割合) |

代表値: レベル 1 は 3 列・6 トレイ・欠片 0、レベル 11 は 5 列・9 トレイ・欠片 3、レベル 60 以降は 15 列・17 トレイ・欠片 18 で頭打ち。

欠片は、行か列を満杯にしてしまう位置には置かない(開始時に消える列を作らない)。
ピースの出方(重み・救済・fitGuarantee)は既定の config と同じ。**レベルは実験を適用しない**(§4 の前提が崩れるため)。

## 3. 状態と保存

- `GameState` に任意の `level: { no, goal, trayLimit }`、`mode: "level"`、`status: "cleared"` を足す
  (エンドレス・デイリーでは `level` を持たないので、golden と保存形式は変わらない)
- 盤のセル値 7 = 欠片
- 端末に保存: `levels`(`{ progress: { "<N>": { stars, score } } }`)と `game:level`(途中のゲーム)

## 4. 解ける面だけを出す(面の表)

固定シードの面は、ピースの巡りが悪いと誰にとっても極端に難しくなる。レベルは順に解放するので、
解けない面が 1 つあると先へ進めない。そこで**ボットが実際にクリアできた面だけを採用する**:

- レベル N ごとにシードの候補 `level:N`、`level:N:1`、`level:N:2`、… を順に試し(最大 40)、
  **レベル 1〜10 は greedy、11 以降は lookahead** のボットがクリアできた最初の候補を採る
- 結果は `src/config/levels-table.json`(200 レベル分)。`npm run levels:table` が作る(0.5 秒)。
  201 以降は候補 0 で遊ぶ
- 表には面に効く config(盤・ピース・配点・レベル)のハッシュを入れる。config を変えて表を作り直さないと
  `npm run validate:config`(ビルドと CI の G1)が止める
- CI の G4 で `npm run sim:levels -- --to 200 --check` が、表のとおりに解けること・目標と欠片が単調に増えること・
  1 列あたりのトレイが単調に減ることを確かめる

既定値の選び方(2026-09-18): 候補のうち lookahead が解ける割合が、レベル 5〜20 でほぼ 100 %、30 で約 75 %、
50 以降で 17〜50 % になる組み合わせを総当たりで選んだ(後半ほど「解ける面」が珍しい = 難しい面)。
最初の案(目標が 40 列まで伸びる)は、レベル 31 以降を lookahead でも 1 面も解けなかった。
トレイ上限はボットの負けにほとんど効かず(負けはほぼ「置けなくなる」)、難しさは目標列数と欠片で決まる。

## 5. 画面

- **ホーム**: 「レベル」ボタン(現在のレベルと星の合計)
- **レベル一覧 `#/levels`**: 解放済みのレベルと星。次に遊ぶレベルを強調。未解放は 1 つ先まで鍵付きで見せる
- **ゲーム画面**(`#/level?n=N`): 上部に「Lv.N」「目標 5 / 10 列」「残り 3 トレイ」
- **クリア**: 星、得点、「次のレベル」「もう一度」「レベル一覧」
- **失敗**: 理由(置けない / トレイ切れ)、「もう一度」「レベル一覧」
